# Настройка GitBook

Эта страница нужна, чтобы визуально привести GitBook к стилю сайта и README.

## Что поставить в настройках

### Title

`SkiF4er`

### Icon

Используй `assets/skif4er-avatar.svg` как квадратный знак.

### Logo

- для тёмного режима — `assets/skif4er-mark-dark.svg`
- для светлого режима — `assets/skif4er-mark-light.svg`

### Theme

Если нужен визуал ближе к сайту, начни с **Muted** или **Clean** и поставь:

- **Primary color:** `#4F8CFF`
- **Tint color:** `#EAF1FB` или близкий холодный оттенок

### Header links

- Сайт → `https://skif4er.ru/`
- GitHub → `https://github.com/TheSkiF4er`
- Telegram → `https://t.me/sf4blog`
- Discord → `https://discord.gg/E52DxpShQy`

### Primary link

Укажи `https://skif4er.ru/`, чтобы клик по логотипу возвращал на основной сайт.

### Footer text

`© 2026 SkiF4er · Независимые системы · Открытый код`

## Важное ограничение

GitBook не поддерживает собственные CSS/JS/HTML прямо из репозитория, поэтому единый стиль здесь достигается через:

1. одинаковые тексты и структуру контента;
2. логотип, иконку и цветовую тему в панели GitBook;
3. единые обложки и ассеты из папки `assets/`.

## Проверка результата

После настройки GitBook должен ощущаться как продолжение сайта:

- тот же тёмный инженерный тон;
- тот же синий акцент;
- те же формулировки и порядок каналов;
- та же идея: Независимые системы. Открытый код.
