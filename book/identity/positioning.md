# Позиционирование и тон

## Формула бренда

**SkiF4er = независимые системы + открытый код + инженерная прямота.**

Бренд должен ощущаться не как витрина ради витрины, а как спокойный слой сигнала над реальной инженерной работой.

## Визуальные токены

| Токен | Значение | Использование |
| --- | --- | --- |
| Background | `#0B0F14` | фон сайта, обложек, аватаров |
| Panel | `#111A24` | карточки, панели, hero-блоки |
| Text | `#EAF1FB` | основной текст |
| Muted | `#93A1B5` | вторичный текст |
| Accent | `#4F8CFF` | кнопки, ссылки, сигнальные элементы |

## Типографика

- **Sans-serif:** системный стек или Inter
- **Monospace:** для подписи, меток, инженерных акцентов
- **Заголовки:** короткие, тяжёлые, без лишних слов
- **Абзацы:** спокойные, читабельные, с фокусом на смысл

## Тон текста

Пиши так, будто объясняешь архитектуру сильному разработчику:

- коротко
- по делу
- без инфошума
- без рекламных превосходных степеней
- с уважением к технической аудитории

## Запрещённые паттерны

- слишком эмоциональные лозунги
- перегруженные эмодзи и декоративные бейджи
- маркетинговый туман вместо точных формулировок
- разноцветные палитры без причины

## Правильный образ

Тёмный, спокойный, собранный, технологичный.
Не «стартап с шумом», а **инженерный контур с собственным вектором**.
