# Системы

Экосистема SkiF4er построена вокруг нескольких продуктовых и инфраструктурных направлений.
Каждое из них решает свою задачу, но визуально и смыслово они должны ощущаться частью одного инженерного контура.

- **CajeerEngine** — ядро экосистемы и инженерный фундамент
- **Arog** — экосистема каркасов и библиотек
- **NexoraCMS** — управляемое CMS-направление для масштаба
- **NovaCMS** — чистая CMS для редакторских сценариев
- **Rog** — российская CMS для операционного контура
